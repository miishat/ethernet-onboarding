# IEEE source excerpts

PDF filenames use these patterns:

- `IEEE-802.3-2022-Clause-119.pdf`: published standard, complete clause or annex excerpt.
- `IEEE-802.3df-2024-Clause-172.pdf`: published amendment that adds a complete clause or annex.
- `IEEE-802.3df-2024-Clause-167-amendment.pdf`: changes to a clause or annex whose base text is elsewhere.
- `IEEE-P802.3dj-D3.2-2026-Clause-175.pdf`: excerpt from the unapproved P802.3dj D3.2 draft dated 29 July 2026.

The same pattern applies to `Annex`. Filenames omit page ranges and compression details. Cite the printed page number inside the PDF, not its viewer page index. For change-only excerpts, consult the base clause or annex together with the amendment.

See [the audit](../docs/ieee-knowledge-base-audit.md) for known source gaps and content checks.
